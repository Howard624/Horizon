### [Google 从 Chrome 网上应用店移除 MV2 扩展并引发热议](https://webiterate.dev/google-removed-extensions-ublock-origin-108/) ⭐️ 8.0/10

谷歌已正式从 Chrome 网上应用店中移除所有 Manifest V2 扩展程序，这标志着浏览器扩展架构向 Manifest V3 迈出了重大转变。此举直接导致包括 uBlock Origin 在内的多款热门内容拦截工具下架，引发了用户对浏览器垄断、广告安全过滤以及向 Firefox 等替代浏览器迁移的热烈讨论。开发者和高级用户普遍对由于缺少有效拦截支持而带来的广告诈骗风险和隐私威胁表示担忧。

hackernews · twapi · 8月31日 21:10 · [社区讨论](https://news.ycombinator.com/item?id=49514878)

**「背景」** Manifest V2 是谷歌 Chrome 浏览器长期使用的一套扩展程序开发标准。随着网络安全和隐私保护需求的演变，谷歌推出了限制扩展权限的 Manifest V3 标准，并逐步淘汰老旧的 V2 版本。

**「影响」** 数以百万计依赖旧版扩展的用户将无法在 Chrome 中继续获得更新或安装这些工具，迫使他们寻找替代方案或转向其他浏览器。

**「社区讨论」** 社区讨论主要集中在对谷歌单方面掌控网络生态的不满、对广告恶意软件安全隐患的担忧，以及呼吁转向 Firefox 等替代浏览器。部分用户虽然对 Firefox 的某些商业决策感到不满，但仍将其视为当前摆脱 Chrome 垄断的核心选择。
